# Game Library

## Description

This project is a text-based game library made in Java.
It allows users to manage and explore a collection of games.

## Features

- View all games
- Search games by genre, platform, or age rating
- View game details and rate games
- Record game sessions
- Add new games

## Classes

- GameLibrary: Stores and manages games.
- Game: Contains the information shared by all games.
- SinglePlayerGame: Represents a single-player game.
- MultiplayerGame: Represents a multiplayer game.
- OnlineGame: Represents an online game.
- GameSession: Records a game and the time played.

## Enums

- Genre: The type of game, such as RPG, sports, or action.
- Platform: Where the game is played, such as PC or PlayStation.
- AgeRating: The recommended age rating for a game.

## Technologies

- Java
- ArrayList
